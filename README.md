Questo progetto è un sito e-commerce completo e dinamico dedicato alla vendita di abbigliamento per uomo e donna, pensato per offrire un’esperienza utente moderna, interattiva e fluida.

Funzionalità principali
	Home page dinamica: suddivisa per categorie (Uomo/Donna), con prodotti mostrati in maniera interattiva.
	Scheda prodotto: ogni articolo ha una pagina dedicata con dettagli completi (nome, descrizione, prezzo, immagini, consegna) e opzioni per:
	  •	Aggiungere il prodotto al carrello
	  •	Inserirlo nella wishlist
 
Carrello:
	•	Elenco dei prodotti selezionati
	•	Quantità aggiunte
	•	Box riepilogativo con subtotale, IVA e totale
	•	Pulsante Paga che trasforma il carrello in un ordine
 
Gestione ordini:
	•	Accessibile dall’area personale dell’utente
	•	Riepilogo di tutti gli ordini effettuati con:
	•	ID ordine
	•	Data e ora dell’acquisto
	•	Dettaglio dei prodotti acquistati
 
Area utente:
	•	Visualizzazione e modifica delle informazioni personali
	•	Gestione dei metodi di pagamento
	•	Accesso alla cronologia ordini
	•	Funzionalità di logout
 
Wishlist:
	•	Aggiunta e rimozione prodotti
	•	Possibilità di trasferire i prodotti al carrello
 
Footer:
	•	Link a FAQ
	•	Link a Termini e condizioni

Il progetto è strutturato per garantire una simulazione completa dell’e-commerce fin dal primo accesso:
	•	All’avvio dell’applicazione, il sistema carica automaticamente una serie di prodotti predefiniti con immagini e dettagli associati, per garantire una visualizzazione immediata del catalogo.
	•	Il back-end gestisce le seguenti entità principali:
  	•	Utente: registrazione, autenticazione, gestione profilo
  	•	Prodotto: informazioni, immagini, categorie
  	•	Carrello: prodotti selezionati, quantità, calcolo totale
  	•	Wishlist: gestione dei preferiti
  	•	Ordine: cronologia acquisti, dettagli transazioni

Front-end
	•	HTML5 – Struttura delle pagine
	•	CSS3 – Stile e layout responsive
	•	JavaScript – Logica interattiva lato client e dinamiche della UI

Back-end
	•	Java – Linguaggio principale per la logica applicativa
	•	Spring Boot – Framework per la creazione di API REST e gestione dell’intera architettura server-side
	•	Spring Security – Per l’autenticazione e la protezione delle rotte
	•	JPA / Hibernate – Per la mappatura degli oggetti Java su database relazionali
	•	MySQL – Database per la persistenza dei dati

Altre tecnologie e strumenti
	•	Maven – Per la gestione delle dipendenze e build del progetto
	•	Postman – Per il testing delle API REST
	•	Git + GitHub – Controllo versione e hosting della repository
